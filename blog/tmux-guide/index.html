tmux终端效率工具

tmux 从会用到用好

按初级、熟练、高级三步走：会话 / 窗口 / pane 的基本操作，复制模式与布局整理，再到关机恢复现场和一条命令开好项目。文中有一个能直接在页面上按键的模拟器。

发布 2026.10.21阅读约 8 分钟

我每天的终端工作都开在 tmux 里：一个项目一个会话，编辑器、服务、日志各占一块，关掉终端软件也不会丢。这篇把我用到的东西按三个阶段整理出来：

  • 初级：能用起来。开会话、分窗口、切 pane、离开再回来。
  • 熟练：用得顺手。复制模式翻历史和搜索、布局整理、调整顺序。
  • 高级：让它替你干活。关机后恢复现场、同步输入、一条命令开好项目布局。

命令以 tmux 3.6 的 man page 为准。按键以我的 ~/.tmux.conf 为准，完整配置放在文末。

先说前缀键

下文的 前缀 指我配置里的 Ctrl-a，tmux 默认是 Ctrl-b。用法是先按下并松开前缀，再按后面的键。例如 前缀 d 就是按一下 Ctrl-a，松开，再按 d。

初级：能用起来

三层结构和基本操作 · 阅读约 15 分钟

学完这一部分，你能开会话、分窗口、切 pane、放大缩小，离开终端后再回来接着干。

三层结构

tmux 把终端分成三层：会话（session）里有多个窗口（window），窗口里切分出多个 pane。

层级 相当于 典型用法
会话 一个工作现场 一个项目一个会话，例如 blog、api
窗口 浏览器标签页 编辑器一个窗口，日志一个窗口
pane 标签页里的分屏 左边写代码，右边跑测试

这三层都由后台的 tmux server 进程持有。关掉终端软件，server 和里面的程序照常运行，这就是 tmux 最大的价值。

要点

我的配置里 base-index 1 和 pane-base-index 1 让窗口和 pane 都从 1 开始编号；renumber-windows on 让关掉一个窗口后，其余窗口自动补齐编号。

熟练：用得顺手

少按键、少用鼠标 · 阅读约 20 分钟 · 前置：初级

初级解决「能用」，这一部分解决「顺手」。最该先练的是复制模式：翻历史、搜索、复制全靠它。其余几节按需取用。

复制模式：翻历史、搜索、复制

我的配置用的是 vi 键位（mode-keys vi），复制会通过 pbcopy 进入系统剪贴板，历史保留 10 万行。

按键 作用
前缀 [ 进入复制模式
前缀 PageUp 进入复制模式并向上翻一页
k / j，Ctrl-u / Ctrl-d 上下移动，翻半页

场景

坑

tmux 默认 前缀 l 是「回到上一个窗口」，但我的配置把 l 改成了「移到右边的 pane」，所以这个功能目前没有快捷键。需要的话，可以另外绑定，例如 bind Tab last-window。

布局一键整理

分屏分乱了，不用手动拖动边框：

按键 作用
前缀 空格 在预设布局之间循环切换
前缀 Alt-1 ~ Alt-7 直接选择某个预设布局

预设布局包括 even-horizontal（左右均分）、even-vertical（上下均分）、main-horizontal / main-vertical（一个大 pane 加一排小 pane）和 tiled（平铺）。也可以用命令指定，例如 select-layout tiled。

调整顺序

会话：靠排序和命名

会话没有固定位置。在 前缀 s 列表里，按 O 切换排序字段，按 r 反转排序。想固定顺序，就在名字前加编号，例如 1-blog。

高级：让它替你干活

恢复、同步、脚本化 · 阅读约 20 分钟 · 前置：熟练

这一部分的东西用得不频繁，但每一项都能省下大量重复操作：关机不丢现场、一次输入发到多台机器、一条命令开好整个项目。

关机后恢复现场

我装了 tmux-resurrect（负责保存和恢复）和 tmux-continuum（负责自动保存和开机恢复），并开了 @continuum-restore "on"。在我的机器上实测：存档在 ~/.local/share/tmux/resurrect/，每 15 分钟自动生成一份。

按键 作用
前缀 Ctrl-s 立即保存（关机前按一下，避免丢掉最近 15 分钟的变化）
前缀 Ctrl-r 手动从最新存档恢复

能恢复什么

内容 默认
会话、窗口、pane 的布局、编号、名字 恢复
每个 pane 所在的目录 恢复
vim、less、tail、htop、man 等程序 重新启动
pane 里显示过的文字 不恢复，需开启选项
npm run dev、ssh、claude 等程序 不恢复，只留下空 shell

同步输入到所有 pane

打开后，在一个 pane 里输入的内容会同时发送到同一窗口的所有 pane。适合同时登录几台服务器执行同样的命令。

坑

忘记关掉同步是常见事故：之后在任一 pane 敲的命令都会在所有 pane 里执行。处于复制模式等特殊模式的 pane 不会收到输入。

弹出窗口

display-popup 在当前画面上浮出一个临时窗口，关掉程序后自动消失，不会打乱已有布局。

-E 表示程序退出后关闭弹窗，-w / -h 设置宽高，-d 指定起始目录。

远程服务器上的 tmux

在服务器上跑长任务时，先 ssh 登录，再在服务器上开 tmux。网络断了，任务也不会中断，重新登录后 tmux attach 就能回来。

本地 tmux 里再 ssh 进远程 tmux，就是「嵌套」：按一次 Ctrl-a 只有本地 tmux 收到。我的配置有 bind C-a send-prefix，所以连按两次 Ctrl-a，就会把前缀发给里层的 tmux。

要点

如果远程服务器的 tmux 用默认前缀 Ctrl-b，就不会冲突：Ctrl-a 控制本地，Ctrl-b 控制远程。
