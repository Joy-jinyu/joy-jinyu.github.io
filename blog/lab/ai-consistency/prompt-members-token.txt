用 HTML + CSS + 少量原生 JS 写一个单文件页面：移动端 H5 的「团队成员」页。

内容从上到下：
- 顶部导航栏：左边返回按钮，中间标题「团队成员」，右边「邀请」按钮
- 一个搜索框，占位文字「搜索成员」，输入时按名字过滤列表
- 「成员 · 6」分组：六行，每行头像、名字、一个角色标签（所有者 / 管理员 / 成员）、一行小字最近活跃时间（如「2 小时前活跃」），右侧一个「更多」按钮，点开是菜单：设为管理员、移出团队
- 「待接受的邀请 · 2」分组：两行，每行邮箱、「3 天前发出」，右侧一个「撤回」按钮
- 页面底部一行小字：Pro 套餐最多 10 人，已用 6 个名额

必须使用下面这组设计变量，不要自己另选颜色、圆角和字号：

```css
:root {
  --color-accent: #b65a3c;      /* 主色 */
  --color-on-accent: #ffffff;   /* 主色上的文字 */
  --color-text: #1c1c1a;
  --color-text-2: #5f5e59;
  --color-line: #e7e6e1;
  --color-bg: #f4f4f1;
  --color-card: #ffffff;
  --radius-card: 16px;
  --radius-control: 10px;
  --font-sm: 13px;
  --font-md: 15px;
  --font-lg: 18px;
  --space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-5: 24px;
}
```
