The page is done and passes every browser check I ran. It's the same colour pair as 「升级套餐」 in the reference card, so changing it would break the match with the existing App. That's a call for whoever owns the App's style.
## Skills loaded

  - `frontend-design`: it aims for a distinctive look, which works against "match the existing card".

## How it matches the reference
- **Colours:** a script compared the colour variables in both files, light and dark. All 13 shared ones have identical values.
  - I added one variable, `--thumb`, for the selected half of the 月付/年付 switch. In dark mode the card colour is darker than the switch track, so reusing it would make the selected half look sunken.
- **Shapes and behaviour copied from the reference:** card (16px radius, 20px padding, same shadow), tag pill, buttons (44px tall, 10px radius, primary and secondary styles), 40px icon button, focus ring, toast, and reduced-motion handling.
- **Where I followed the reference over `ui-conventions`:**
  - The skill's spacing scale leaves out 20px, but the reference uses 20px for card padding, so I kept 20px.
  - The skill wants a tooltip on icon buttons. The reference's icon button has only a label for screen readers, so the close button does the same.
## Checks before delivery
I ran a Playwright script in headless Chromium; the script and screenshots are in the session scratchpad.
**Not checked:** a real iOS Safari or in-app WebView, VoiceOver, and enlarging only the text size (fonts are in px, as in the reference).

**加载的 skill**

**读过的文件**
- 只列了 `ai-consistency/` 目录的文件名，没有打开里面的 `prompt-*.txt`，也没看其他 lab 目录里的页面。
**交付前的检查**
- **设计变量（已验证，脚本输出）**：
  - 文件里扫描：给定的 `:root` 块之外没有任何颜色值，所有字号和圆角都引用变量，没有内联 SVG。
  - 浏览器里扫描：页面上所有元素（含伪元素）实际算出来的颜色，全部落在那 7 个颜色变量里。唯一例外是两个视觉隐藏的单选框，浏览器默认给黑色，但尺寸 1×1 且被裁掉，不会画出来。
- **对比度（已验证，按实际渲染的颜色计算）**：18 组文字都 ≥ 4.5:1，最低的是主色底白字，为 4.65。另外，主色文字放在 `--color-bg` 底上只有 4.22，不够小字的 4.5，所以页面里没有这样用。
- **明暗主题（不适用）**：给的变量只有浅色一套，加深色就得自己选颜色，所以固定为浅色。
**变量之外加的几个值**：
- 触控尺寸 `--size-touch: 44px`（单独写在一个 `:root` 里，附了出处注释）。
- 页面最大宽度 480px，只是为了在桌面上预览时不被拉宽。
- 切换器内层的圆角写成 `calc(var(--radius-control) - var(--space-1))`，也就是 6px，是从两个变量算出来的，不是另选的值。
- 主按钮按下时透明度降到 0.85。
- 线宽、焦点框、图标尺寸用了 1px、2px 这类写死的数值。
