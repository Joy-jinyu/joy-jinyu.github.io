三个需求，每个交给两个全新的 Claude Code subagent（Claude Opus 5.5，2026-10-29），共 6 份。
prompt 里只有需求和输出路径，没有设计规范；subagent 会继承这台机器的全局配置 ~/.claude/CLAUDE.md。

==== 折叠面板（accordion1.html、accordion2.html）====
用 HTML + CSS + 少量原生 JS 写一个单文件页面：移动端和桌面都能用的「常见问题」折叠面板。

内容：
- 标题「常见问题」
- 6 个问题，答案长短不一，最长的一条有三段文字和一个列表
- 点问题展开答案，再点收起；同一时间可以展开多个
- 展开和收起要有动画

把完整代码写到这个文件：……/accordion1.html

==== 通知（toast1.html、toast2.html）====
用 HTML + CSS + 少量原生 JS 写一个单文件页面：一个「通知」演示页。

内容：
- 页面上三个按钮：「保存成功」「上传失败」「新消息」
- 点一下就弹出一条对应的通知：桌面在屏幕右下角，手机在顶部
- 通知可以同时存在多条，依次堆叠
- 每条 4 秒后自动消失，也可以点 × 手动关掉
- 进场和退场要有动画

把完整代码写到这个文件：……/toast1.html

==== 底部面板（sheet1.html、sheet2.html）====
用 HTML + CSS + 少量原生 JS 写一个单文件页面：手机 H5 上的「分享」底部弹出面板。

内容：
- 页面上一个「分享」按钮，点了从底部弹出面板
- 面板里一排分享渠道（微信、朋友圈、QQ、微博、复制链接）和一个「取消」按钮
- 点遮罩或「取消」关闭
- 面板可以用手指往下拖动来关闭，拖得不够远就弹回去
- 打开和关闭要有动画

把完整代码写到这个文件：……/sheet1.html
